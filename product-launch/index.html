5-Stage Pipeline

The TRACE
Evidence Lifecycle.

From device intake to court-admissible proof seal — every byte is tracked, hashed, and grounded.

01
Intake & Vault

Evidence Ingestion & Sandbox Vault

The user selects evidence from Camera, Gallery, Audio, or Files. TRACE immediately copies each file into an application-private vault — inaccessible to all other apps. SHA-256 is computed over the preserved bytes before any processing begins. Every ingestion event is timestamped and registered in SQLite.

SHA-256 /data/user/0/com.trace.forensic/ SQLite trace_vault.db
02
Multimodal Extraction

On-Device OCR & Audio Transcription

Google ML Kit's offline Latin Text Recognition extracts text from screenshots, chat images, and documents without sending a single byte to the cloud. Whisper.cpp decodes audio evidence as 16kHz mono PCM via Android MediaCodec, transcribing voice messages and recorded calls entirely on-device. All extracted content is marked as derived data — it supplements, never replaces, the original.

ML Kit OCR Whisper.cpp GGML Tiny 16kHz PCM JNI Bridge 100% Offline
03
Edge AI Reasoning

Gemma 2B On-Device Forensic Analysis

Google MediaPipe LLM runs Gemma 2B INT4 quantized locally — classifying incidents (BLACKMAIL, EXTORTION, COERCION), attributing suspect entities and UPI payment IDs, identifying financial demands, and linking every assertion to a specific source evidence UUID. Hallucinated claims that lack valid provenance are automatically rejected by the grounding validator.

Gemma 2B INT4 MediaPipe LLM sourceEvidenceId Grounding Validator Zero Hallucination Policy
04
Cryptographic Integrity

Sequential Hash Chain Ledger & Tamper Audit

Every forensic operation — import, OCR, transcription, analysis, export — is appended as an immutable node to an append-only cryptographic hash chain. Each node's hash is computed from its payload hash chained to the previous node: chain[N] = SHA-256(chain[N-1] + payload[N]). Any tampering anywhere in the chain is immediately detected.

Hash Chain Ledger Append-Only Real-Time Tamper Detection [TAMPERED] Alert
05
Court-Admissible Export

Proof Seal & Section 65B Report Generation

TRACE auto-generates a structured PDF report compliant with Section 65B of the Indian Evidence Act (Bharatiya Sakshya Adhiniyam). The report includes officer credentials, case metadata, the complete evidence chain, grounded findings, and a hardware-signed Ed25519 cryptographic proof seal — exportable in one tap via Android's native share sheet.

Section 65B / BSA Ed25519 SIG_TRACE_HARDWARE PDF Report Native Share

Core Capabilities

Built for Real
Forensic Work.

Cryptographic Chain-of-Custody

Every ingested file is SHA-256 hashed at intake. Every downstream operation is appended immutably to a sequential hash chain. Any post-intake modification is detected instantly.

Air-Gapped Privacy Vault

All evidence, model weights, databases, and processing remain inside the device's private application sandbox. Zero mandatory cloud upload. Zero network dependency for core forensic functions.

On-Device Gemma 2B LLM

Google MediaPipe runs Gemma 2B INT4 locally. Classifies incidents, attributes actors and UPI IDs, identifies demands — all assertions linked to source evidence UUIDs with zero hallucination tolerance.

Deterministic Timeline

Incident chronology is governed by verified timestamps: EXIF → user-specified → embedded → import. Events are categorised as Verified, Inferred, Uncertain, or Rejected — AI never fabricates chronology.

Section 65B Court Reports

Auto-generates PDF reports compliant with the Indian Evidence Act / BSA, complete with officer credentials, grounded findings, hash manifests, and a hardware Ed25519 cryptographic proof seal.

Multimodal Extraction

Google ML Kit extracts text from screenshots and documents 100% offline. Whisper.cpp transcribes voice evidence via Android MediaCodec at 16kHz. All derived data is preserved separately from source evidence.
